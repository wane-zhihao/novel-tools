# 细纲（第 2 章）

## 第 2 章：老会计的茶缸

- 核心事件：三天期限只剩两天，陈砚摸清赵德海急着逼认是因为厂办经手的那摞账麦收前要往上报、如今锁进了铁皮柜；他两度去堵当年经手交接的老会计孙有田，不逼不问账，只按时序复述当年交接的三个先后，点破孙有田「记得却不敢说」的心病，孙有田松口「批斗会上我照老规矩说」；许晚晴在车间门口当众不附和污名，完成关键亮相。
- 字数目标：2500 字（按卷纲 2500 排期，单章区间 2000–2500）
- 字数口径：visible_chars_v1
- 单元ID/位置：第一幕 · 掀榜（`大纲/卷纲_第一卷.md` 第三节 3.2，ch1–12）/ 本幕第 2 章、第 2 拍：人证侧写位——S4 从「会不会开口」推到「只肯说交接」，S3 埋设（`大纲/卷纲_第一卷.md` 第五节 5.1）
- 目标情绪：从期限压顶、四面无人可问的孤立无援（前状态）→ 摸到赵德海为什么急时的冷静笃定 → 眼看孙有田转身就走、话被堵死时的憋闷 → 点破对方心病、听见「照老规矩说」时的一口气松开（后状态）；本章只推进「愤怒与憋屈里第一次摸到缝隙」这一环，不提前给翻盘的痛快。
- 主角目标/关键选择：陈砚要在两天内找到唯一记得当年交接顺序的人并让他开口；他的关键选择是不拿「你当年经手、你脱不了干系」去逼、也不许好处去诱，而是按时序把孙有田自己做过的事一件件摆出来，让他自己坐不住——因为逼出来的证词一到会上就会被翻，只有让对方自己认下「照老规矩」，那句承诺才立得住。
- 章首钩子：当场冲突——天没亮，陈砚在车间后门废料棚堵住孙有田，孙有田一见他，料筐往地上一放就要退回车间，甩下一句「你别问我，我什么都不知道」，前 200 字内冲突到位。
- 爽点：不威逼不利诱的降维压制——陈砚不报账、不算账，只把孙有田当年「先谁后谁、算盘推到桌角、复写联压在茶缸底下」这三个先后摆出来，孙有田手抖得茶缸盖磕在缸沿上响了两声，反问他「你怎么记得这么清」；读者的爽感来自「他手里那本别人看不见的账」第一次落到具体的人身上。
- 本章禁止提前释放：账目窟窿的具体内容与量级（只露「麦收前要交」的边·S3 收在 ch52）、赵德海找孙有田时说的原话与拿捏手段、孙有田在批斗会上具体要说什么（ch3 兑现）、许晚晴的婚约压力（S9 埋在 ch8）

### 内容概括（五段式）

- 起因：三天期限过了一夜只剩两天，陈砚把昨天的场面从头到尾排了一遍，认定赵德海急着逼他三天内认账，不是因为他真有一笔对不上的账，而是厂办经手的那摞账等不起——要捂账，最省事的办法是先找一个人把名顶上；而要证明「账目不清」不是他一个人的事，全厂只有当年跟他办交接的老会计孙有田说得清先后。
- 发展：陈砚天没亮就到车间后门的废料棚堵人，孙有田一见他，料筐往地上一磕，转身要回车间，把话堵死「你别问我，我什么都不知道」；陈砚不追、不问账，只改口问「那天早上谁先进厂办」，孙有田绕开不答，收料时却漏出一句「主任昨儿散场后找过我，让我少说话」——这一句让陈砚明白，赵德海比他更怕孙有田开口。
- 转折：陈砚绕到厂办后窗，看见赵德海把一摞单据往铁皮柜里锁，压着嗓子催人「麦收前这摞得交上去，别再翻」；同一时候车间门口几个青工围着劝他「认了吧，别拖累你爸」，推着自行车进厂送供销社单子的许晚晴停下车，当众说「账没核过就定人，不合你们厂的规矩」，又提醒他别在车间门口站着说话——全厂都听得见。
- 高潮：陈砚改到孙有田回家的老槐树下等，按时序把当年交接的三个先后摆出来：先进厂办的是孙有田，他把算盘往桌角一推说「账要清才签字」，签完字把复写的那一联压在自己茶缸底下；陈砚只说一句「您记得，您只是不敢说」，孙有田手抖，茶缸盖在缸沿上磕了两声，反问他怎么记得这么清。
- 结尾：孙有田终究没答应作证，只从牙缝里挤出一句「批斗会上我照老规矩说」，走了两步又回头补一句「我只说交接，账一个字不提」；陈砚站在老槐树下回头望，厂办那扇窗还亮着，铁皮柜的锁扣在灯下泛着一点光——那摞麦收前要交上去的账，到底是什么账。

### 情节安排（多线）

- 主线推进：S4（孙有田记得多少、会不会开口）从「不知底」推到「松口只肯说交接」，为 ch3 批斗会反水立下第一句承诺；S3（厂办经手对不上的账）在本章埋设——麦收前要交、锁进铁皮柜、赵德海压着人「别再翻」；S1 倒计时由三天递减为两天。
- 辅线推进：情感线（许晚晴，卷纲 3.3 配比表约一成份额，ch2 起关键亮相）从「榜前旁观者」推到「当众不附和污名并递一句提醒」；卷纲未设 L 编号体系，本章按线索名记账。家庭线不动，只在青工那句「别拖累你爸」里带一下。
- 事件线 / 任务线：外部事件链＝堵人 → 被当面回绝 → 从话缝里摸到赵德海提前打过招呼 → 隔窗看见账被锁进铁皮柜 → 换场地再找 → 点破心病 → 拿到一句口头承诺。卡点：孙有田当面闭门、赵德海已抢先封口；卡点变化：从「不肯见」松动为「只肯说交接」。
- 感情线 / 关系线：无显性感情推进；关系变化为——许晚晴从「认得的脸」变成「当众替他说过一句公道话的人」，陈砚记住这个人但不当场攀谈；孙有田从「躲」变成「应下一句只讲交接的话」。
- 逻辑线：因为期限只剩两天而账目是非只能靠人对先后 → 所以陈砚先弄清赵德海为什么急着逼认，再去找唯一记得当年交接的孙有田 → 结果孙有田肯在批斗会上照老规矩说 → 新问题：他只肯说交接、账一个字不提，而那摞账还锁在赵德海的铁皮柜里。

### 人物关系和出场顺序

- 出场顺序：陈砚 → 孙有田（车间后门废料棚，料筐）→ 车间后门的废铁堆 → 厂办后窗与铁皮柜（赵德海隔窗，只闻其声）→ 车间门口围劝的青工 → 许晚晴（自行车、供销社送货单）→ 老槐树下的孙有田（第二次）→ 章末的厂办窗灯与铁皮柜锁扣。
- 人物关系变化：本章前 → 本章后——孙有田以为这桩事早没人记得清，躲过去就能安稳退休 → 被陈砚把三个先后摆到脸上，躲不干净，只肯应下「照老规矩说」；赵德海以为当众定性＋限期已经把人钉住 → 不知道陈砚已经摸到他急着交账的来处；许晚晴与陈砚本是点头之交 → 她当众替他说了一句，两人之间多了一句可以还的人情。
- 视角/信息差：读者知道陈砚有前世十年的档案记忆、记得全厂的先后，也看见铁皮柜里那摞账；孙有田不知道陈砚记得这么细，只当他是个被逼急了的青工；赵德海不知道陈砚已经在窗外看见了锁账那一下；陈砚本章的误判＝他以为这窟窿只是赵德海一个人的事，没想到厂办经手的人一串都在里头（此层到卷末才翻）。本章读者认知按 `追踪/时间线/读者已知.md` 当前六条（E001–E006）的初始状态续写，不新增读者侧结论。

### 结尾设定和钩子

- 结尾设定：收束落在老槐树下孙有田回头补的那句「我只说交接」和厂办窗里那点灯上，镜头最后停在铁皮柜的锁扣；未解决问题：孙有田只肯说交接，账一个字不提，而「账目不清」要洗清，绕不开那摞麦收前要交的账；下一章推动力：期限只剩两天，批斗会上孙有田会不会真按老规矩开口，赵德海又为什么非赶在麦收前把这摞账交上去。
- 章尾钩子：悬念悬置（新疑问）——孙有田松了口，可他只肯说交接；厂办那本对不上的账到底是什么，为什么赵德海压着人「麦收前交上去、别再翻」；期待度：强；与下一章承接：ch3 批斗会开场，赵德海逼认，孙有田被逼到崩、当众按老规矩交出凭证，本章这句「照老规矩说」当场兑现。
