# 细纲（第 1 章）

## 第 1 章：榜上换了名

- 核心事件：顶职公示当天，陈砚在厂前宣传栏看到顶职名单上自己的名字被换成亲弟弟陈磊，厂办主任赵德海当众宣布他「账目不清」并殃及父亲陈广田三十年清誉，限期三天认账，不认即按侵占公款除名移交。
- 字数目标：2500 字（卷纲排期上限偏上，为逐章返工留余量）
- 字数口径：visible_chars_v1
- 单元ID/位置：第一幕 · 掀榜（`大纲/卷纲_第一卷.md` 第三节 3.2，ch1–12）/ 本幕第 1 章、第 1 拍：开篇危机引爆位（`设定/题材定位.md` 开篇结构 018 双 pattern：前 200 字「顶替＋污名＋当众」，前 600 字「限期逼认、避无可避」）
- 目标情绪：从重生归来的错廓不敢信（前状态）→ 当众受辱、父亲清誉被点名时的压抑怒火 → 三天期限落定后的脊背发凉、避无可避（后状态）；点燃全书愤怒结构第一环——羞辱主角本人不够，必须殃及长辈清誉（`设定/世界观.md` 世界规则 3、4）。
- 主角目标/关键选择：陈砚要在当众换名＋当众定性的死局里不认罪、也不当场掀榜——认了即坐实侵占公款并除名，掀榜即授人以柄「抗拒到底、罪加一等」；他的关键选择是按住冲动，用前世管档案十年养成的记录员本能，把赵德海当众宣布罪状的顺序一条条记住，把三天期限当作翻盘的唯一缝隙。
- 章首钩子：当场冲突——公示榜前当众换名＋当众定性三合一，前 200 字内冲突必须到位（名单换名当众发生、污名殃及父亲清誉当众宣布）。
- 爽点：隐忍取证的反差爽点——全场等着看他崩溃或咆哮，他一个字不改地把对方的罪状按顺序复述记录，把羞辱现场变成自己的取证现场；读者知他有前世十年档案记忆，打脸前奏的期待感在 Chapter 内拉满，兑现不在本章。
- 本章禁止提前释放：孙有田人证反水（ch3 兑现）、陈砚前世记忆细节（只露「记得顺序」的边）、名额回到他名下的结果（S2 埋而不收）、致富线与许晚晴（ch2 起亮相）

### 内容概括（五段式）
- 起因：陈砚重生回到 1983 年初夏顶职公示当天，因为知道「当年的顺序」会怎么走，他赶到厂前宣传栏时还存着拦住换名的最后指望——榜前挤满人，顶职名单上他的名字已经变成了「陈磊」。
- 发展：厂办主任赵德海当众把他经手的账目定性为「对不上」，把名额之争升级成侵占公款嫌疑，并当众点到父亲陈广田三十年老工人的清誉；人群哗然，污名从陈砚一个人烧到陈家两代人。
- 转折：亲弟弟陈磊当场倒戈，指着哥哥补上最狠一刀；母亲王秀兰挤进来拉他袖子劝「认了算了，别连累全家」——陈砚不吵不认，只当众问出第一个问题：公示换名之前，名单经手人是谁。
- 高潮：赵德海顺势定下三天期限——认账即除名，不认即按侵占公款移交追查，把「认与不认都是死」的避无可避局当众钉死；陈砚在满厂围观里逐条复述对方宣布的罪状顺序，把羞辱现场变成取证现场。
- 结尾：人群散去，夕阳压在公示栏「陈磊」三个字上；陈砚在笔记本上记下今天的顺序，离认账期限还有三天——全厂都等着他低头，他偏不低。

### 情节安排（多线）
- 主线推进：厂线（名额＋污名）本章同时埋设 S1「限期认账」与 S2「名额归属」两枚大悬念；主线由「公示换名」推进到「限期逼认、避无可避」，名额与污名的双重危机正式压顶（`大纲/卷纲_第一卷.md` 第五节 5.1）。
- 辅线推进：无显性辅线拍数；家庭线仅随开篇引爆结构到位（母亲劝认、父亲清誉被殃及），偏心账记入 S6（ch9 兑现），本章不推进、不回答。
- 事件线 / 任务线：外部事件链＝公示换名 → 当众定性 → 限期逼认；卡点：认与不认都通向除名或移交追查，唯一的缝是「三天」。
- 感情线 / 关系线：无显性；但关系变化为：与母亲当众掰破「大的让小的」的默契，与陈磊从兄弟变成当众指证的对手，与赵德海从上下级变成限期追缴的死对头。
- 逻辑线：因为重生归来、知道事情在按当年的顺序重演 → 所以他不认罪也不掀榜，先把当众宣布的每句话按顺序记住 → 结果三天期限落定、除名威胁压顶 → 新问题：三天内拿不出反证就是移交追查，而证据只锁在他前世的记忆里。

### 人物关系和出场顺序
- 出场顺序：陈砚 → 公示栏顶职名单（关键物件）→ 赵德海 → 围观青工 → 陈磊 → 王秀兰 → 陈广田（被当众点名、清誉被殃及，只在人群边缘露一面或只闻其声）→ 陈砚笔记本上的记录（章末特写）。
- 人物关系变化：本章前 → 本章后——母亲以为大儿子还会像从前一样认命 → 被他当众掰开手；陈磊以为哥哥蒙在鼓里 → 被「经手人是谁」当众问住；赵德海以为污名一压就塌 → 对方不吵不认，只把他说的每句话都记了下来。
- 视角/信息差：读者知道陈砚重生且记得当年全部顺序（章内只点「他知道事情在按当年的顺序走」的边，不展开记忆内容）；全场人只当他是个被当众定性的嫌疑人；赵德海知道账目有窟窿、不知道陈砚记得顺序；主角本章不当众亮记忆，误判风险＝说早了没人信、说错了罪加一等（按 `追踪/时间线/读者已知.md` 当前空表的初始状态，本章为读者建立第一层认知）。

### 结尾设定和钩子
- 结尾设定：收束落在公示栏「陈磊」三个字被夕阳压着的画面，切到陈砚笔记本上按顺序记下的条目（日期、名单、经手人、当众宣布的罪名顺序）；未解决问题：三天内拿不出反证就是移交追查，而证据只锁在他前世的记忆里；下一章推动力：限期倒计时＋他要找当年经手的人对顺序。
- 章尾钩子：期限压迫（倒计时）——离认账期限还有三天，全厂都等着他低头，而唯一能证明他清白的是他前世十年记住的「谁、在什么场合、按什么顺序做了什么」；期待度：强；与下一章承接：ch2 转入第一次暗线动作（找顺序、认人证），并完成许晚晴「不附和污名」的关键亮相。
