## 一、主线一句话

**陈砚要凭「人事时序记忆」按时序口述事实链，拿回被亲弟弟陈磊顶掉的顶职名额、洗清殃及父亲三十年清誉的「账目不清」污名，并把幕后捂账目窟窿的厂办主任赵德海当众钉死；挡路者 = 陈磊 + 赵德海 + 偏心父母（王秀兰、陈广田的门户压力）。**

拆解对齐（一句话必须同时答全「做什么 / 谁在挡」）：

| 要素 | 内容 | 依据 |
|---|---|---|
| 主角要做什么 | 拿回名额 → 洗清污名 → 护住父亲清誉 → 钉死赵德海 | 角色.md 陈砚一句话动机 |
| 谁在挡 | 陈磊（倒戈指认）、赵德海（定性权+限期逼认）、偏心父母（劝认、偏心土壤） | 角色.md 开篇挡路者、势力.md 三 |

## 二、卷末高潮（第 52 章 · 全员举证大会）

**场地即闭环**：决战放在开篇批斗会的同一个会场（世界观.md 关键场景：同一空间两次转向）——赵德海把「逼认账」的批斗会开成「绝后患」的终审会，陈砚把它开成赵德海的塌方会。

| 组件 | 设计 |
|---|---|
| 赵德海的底牌（ch51 出尽，ch52 收割） | 绝境中把账目窟窿说成「厂里历年惯例」，拉全厂办下水；同时当众暗示陈广田当年也经过手，妄图再次把火烧向父亲清誉 |
| 陈砚的打法 | 全量时序口述：从公示当天倒着摆到「麦收后」厂办的那一夜（S11 兑现），一环一证；不演算账目，只摆「谁、在哪、按什么顺序」 |
| 人证连环反水 | 孙有田按老规矩「交接要清、签字要认」交出当年凭证；被递话的青工当众暴露（S10 已兑现的余波）；陈磊最后反水指证赵德海唆使（ch51 出尽，ch52 收割） |
| 结局 | 赵德海当众崩落、停职移交追查；名额与清誉完全落定；父亲陈广田当众认下大儿子（S18 兑现）——第一个打脸位（母亲）之后，家门当面重修 |
| 卷二钩（S13 兑现于卷二） | 赵德海崩落前经手外送的不止厂里这一笔——指向厂外货流渠道，与致富线合流，构成第二卷主引擎 |

## 六、继承设定的写作纪律（细纲/正文执行）

1. 开篇严格执行 018 双 pattern：前 200 字「顶替+污名+当众」殃及父亲清誉；前 600 字「限期认账、避无可避」；三章内人证时序反转（第一卷幕即兑现）。
2. 金手指 = 人事时序记忆：记忆对象是人与事，不是文书与账表；翻盘靠口述事实链，不开算账戏。
3. 反派全部死于「顺序」而非死于拳头；污名结构必须殃及长辈（父亲）清誉。
4. 逐章跑 style_probe / clarity_org_probe：因果显式 ≥1.1/千字、数字密度 ≤2.44/千字、叙述动作 ≤39/千字；章节间波动本身是硬伤。
5. 政策类数字全书 ≤2 处、每处 ≤1 个且用汉字小数；不排比罗列年份/金额/工分。
