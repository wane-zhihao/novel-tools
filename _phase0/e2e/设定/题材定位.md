# 题材定位：都市民俗玄学（异闻档案 / 民间禁忌调查）

> 来源：《选题报告》（N04 打回改写版）第三节结论，五维加权最高候选 A（8.50）。

## 1. 平台与分区

- 平台：纵横中文网（VIP 付费男频站）。
- 投稿分区：**都市**（男频主力；genre-baselines 中唯一 n=24 强样本组）。
- 邮件标题格式：《书名》+ 都市 + 字数，一稿只投一位编辑。
- 禁止标签：悬疑、灵异、玄学——避免分流延误。

## 2. 核心概念

**一个没有阴阳眼的档案协查员，用方志、口述史、旧报纸和档案编号，给每桩「异闻」找出现实解释层。**

- 都市异闻 = 被民俗禁忌包装起来的人事事件。全书不出现确认的超自然力量。
- 每桩异闻必须三层落地：① 禁忌内容（民俗）② 人事动机（谁借用了它）③ 证据链（方志 / 口述史 / 旧报纸 / 档案编号至少两类互证）。
- 主角的工具只有四样：方志、口述史、旧报纸、档案编号。

## 3. 四个编辑可见的差异化设定

1. **主角无异能**——没有阴阳眼、没有系统、没有师门；「异象必须有现实解释层」。
2. **章名 = 档案编号**——形如「异闻档案·017｜腊月不搬家」，编辑看目录即知结构。
3. **三拍固定结构**——接案（编号入档）→ 现场（考据细节当证据链）→ 归档（真相 + 处置 + 代价），翻任意一章可验证。
4. **章末「卷宗附注」**——注明本章所用民俗的真实出处（如《清嘉录》、地方志卷次），把考据质感变成排版上可见的实体。

## 4. 章节经济学

- 单元剧：一个异闻 = 一条完整证据链 = 一章的结算物（真相、处置、代价）。
- 每章三层结构：**交付**（真相+处置+代价）+ **钩子**（下一档案编号预览）+ **挂账**（每 5–8 章挂长线账，3 章内兑现一次小账）。
- 长线账「七年周期」：1996 / 2003 / 2010 / 2017 四批同源异闻，预测下一批 2024；第 1 章末挂出，每卷还一小笔，第 3 卷末起还大笔。
- 主角私账：2017 年「龙潭沉箱」旧案（其父沈崇山失踪），第 2 卷末与周期交汇。

## 5. 目标读者与承诺

- 男频都市付费读者；承诺「每章一个完整可结算小单元 + 考据质感」。
- 风险声明（如实）：热度维度全报告 `[无实证，属推断]`，不作为选型依据；留存率 ≥15% 与文本特征的关系未知，本设定只覆盖可控部分（前 3 章追读、每章交付稳定性、挂账—兑现节奏）。

## 6. 不写清单（避烂梗）

- 不写：系统提示音、签到、开局无敌、退婚流、天生阴阳眼、天师斗法、境界铺陈。
- 写：基层流程、档案编号、考据、人情与代价。
