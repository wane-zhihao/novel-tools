# 题材定位

> 依据：`大纲/选题报告.md` 第四节「结论」——选定**候选 1：都市 · 90 年代重生实业**（暂名《我在九三收厂》），加权 9.45。

## 一句话定位

1993 年下岗潮前夜，一个被厂子踢出门的年轻人靠「家电产业链」这一个信息差，
一步步把厂子、把家人、把自己的人生收回来。

## 90% 套路 / 10% 创新（严格配比，不许加码）

**90% 成熟骨架（读者零学习成本）**
1. 重生回 1993，带着后视记忆。
2. 信息差变现（哪年涨价、哪种货会缺、哪家厂要改制）。
3. 下岗潮大背景，全家命运压在厂子上。
4. 打脸看不上主角的亲戚 / 车间领导 / 同行。
5. 兄弟合伙、讲义气、分账清楚。
6. 改写家人命运（父母的病、妹妹的学费、老宅）。

**10% 唯一创新抓手**
- 金手指**不做全能**，只锁死在**家电产业链**这一条线：修彩电 → 收旧机 → 拿配件渠道 → 承包维修部 → 收厂做整机。
- 用改制、进货、货款账期、渠道、批文这些硬细节，替代「随口报股票代码」。
- **不做跨界全能、不加系统面板、不写商战黑话**，读者只需接受一个新设定。

## 每章交付单位（对付费站的正面回答）

付费站防的是**注水**，不是划走。本章节的最小交付单位三选一，每章必须兑现一个：
- 一笔生意（谈成 / 砸了但学到）
- 一个订单（拿到手 / 被人截胡）
- 一次正面对抗（打脸、摊牌、抢货、护人）

写完一次完整交付用 1700–1900 字即可，**不硬拉到 3000 字**。

## 明令禁止（红线）

- 禁医武双修、退婚流、战神归来、系统抽奖、纯抄诗（选题报告点名的最饱和烂梗）。
- 禁女频年代文写法：军婚、纯情感流、知青抒情向。
- 禁商战黑话与数据报表式陈述；商业过程必须落到「人、货、钱、场面」。
- 禁把爽点押到 3 万字以后。
