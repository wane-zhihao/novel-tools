# 世界观

> 一句话：**1993 年的江北市，一个国企改制前夜的城市**。世界规则不是魔法，是「物价、批文、货款账期、人情关系」。
> 只做背景板，不抒情；不引入任何超自然力量（重生是唯一例外，且不解释原理）。

## 一、时代坐标

| 项 | 设定 |
|---|---|
| 年份起点 | 1993 年 3 月（重生落点） |
| 时间跨度 | 全书约 1993 – 1998（改制 —— 下岗潮 —— 家电普及 —— 民营整机兴起） |
| 地点 | 江北市（虚构中型工业城市），老工业区 + 电子一条街 + 火车站批发市场 |
| 核心单位 | 红旗无线电厂（国营中型厂，做收音机起家，彩电转型失败，待改制） |
| 社会底色 | 铁饭碗正在裂开；工人怕下岗，倒爷怕严打，个体户怕被叫「投机倒把」 |

## 二、世界运行的硬规则（必须每章兑现）

1. **票证在退场，钱开始说话**。粮票还没废，但彩电、配件、钢材已经认钱和条子。
2. **批文与渠道 = 硬通货**。拿不到「计划外」渠道，有钱也没货；这条是全书最大的对抗源。
3. **货款账期就是命**。上家要现款，下家要赊账，中间那一截就是主角的全部腾挪空间。
4. **技术靠人，不靠文件**。图纸、调机手感、故障经验在老工程师脑子里，人一走就断代。
5. **信息差有保质期**。每一次靠「知道未来」赚到的钱都有窗口，窗口一关就得靠真本事。
6. **关系网决定上限**。厂办、街道、信用社、工商、运输队，五道门，每一道都要人。

## 三、金手指的边界（写死的约束）

- **只锁家电产业链**：修彩电 → 收旧机 → 配件渠道 → 承包维修部 → 收厂做整机。
- 主角知道「趋势」（哪类家电会普及、哪种货会缺、哪家厂会倒），**但不知道细节数据**：
  记不住股票代码、说不出具体型号参数，需要人（马青山）和设备来落地。
- **无系统、无面板、无任务提示**。回忆仅作判断依据，不作旁白解说。
- 用得越多，越容易被人怀疑「你哪来的消息」——这是主角的社会性风险，贯穿全书。

## 四、空间地图（写作时固定使用）

- **红旗厂区**：三车间（主角原工位）、厂办楼、家属院 3 号楼、厂门口小卖部。
- **电子一条街**：配件摊、修机铺、走私板子黑摊，主角起步的地方。
- **火车站批发市场**：货源与倒爷聚集地，第一章的麻烦就出在这。
- **城市信用社**：苏敏的柜台，资金闸门。
- **长顺家电商行**：罗长顺的地盘，中后期主战场。
- **南方特区（深圳 / 东莞）**：货源上游，第二、三卷的进货款来源。

## 六、禁忌（世界观层面）

- 不出现不可解释的力量；不出现穿越者联盟、平行世界、外星科技。
- 不写官场深度斗争（平台与题材风险），冲突一律落在厂内、商场、家庭三条线。
- 不写具体真实企业与真实人物负面；地名、厂名、品牌全虚构。
- 不靠时代悲情推进剧情，时代只提供阻力与机会。
