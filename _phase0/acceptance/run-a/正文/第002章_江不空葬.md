# 异闻档案·042｜江不空葬

七点四十，档案室的门开着。昨夜他锁了两道，锁没坏。所以是从里头开的。

本子躺在门内地上，摊开那页正对门。原来是留给他看的。

三秒之后他才弯腰。原来这四页纸比他急。

那页是三月十一日，三户口述，一个字没少。难怪只撕后四页。

四页齐口，平得能拿尺子对上。原来是比着撕的。

封面上多一道折角。怪不得提得那么顺手。

脚步已经下到二楼。人走得不急，所以急的只有他。

追下去能拿到什么？一双鞋，换不回四页纸。

所以他不追，坐下写日期：三月十六日。

再写三个字：缺四页。笔尖在「缺」上停一下。

墨洇开一点，像颗痣。

手机响。韩素秋的声音不带起伏。

「042。龙潭滨江迁坟，停工两天。」

「冯家老太太一柄铁锹横在履带前，三户，谁都不让动。」

「协查入库，限期一周。工程方等不了七天。」

七天。工程等不了七天，他手里也少着四页。

江边风硬，三座坟一字排开。土是新翻的，难怪草没长回来。

挖掘机停在坡下，履带上一层干泥。怪不得没人敢挪。

铁锹横在履带前，锹头朝东。蓝布条新缠的，不怕人看。

冯桂英坐在矮凳上，七十四岁，膝盖盖一条旧毛巾。

她不理机器，也不理人，只看坟头。原来她守的那座坟，比任何价码都重。

「江不空葬，空葬绝户。」她一个字一个字往外放。

邻家两户跟着点头，点得比她说得还快。难怪口径一样。

沈砚翻开新本子逐字记，记完才问：「空葬是棺空，还是穴空？」

老人停了两秒。

这一停，和041那天顾秀英的一停，是同一个停法。

「坟空了就绝后。」她答。答得不对题。

他问哪一种空，她答空了的后果。所以她听懂了，只是不肯说。

她要是随口编的，为什么偏偏停在这两个字上？

倪长根在挖掘机旁，两手插在袖筒里。手插着，话就轮不到他说。

「老人讲究，我们不敢动。」他只这一句，说完看履带。

沈砚低头。告示四角压着透明胶，边已经翘了。原来贴上没几天。

施工单位：恒岳置业龙潭滨江项目部。承包人倪长根。

说不敢动的人，正是这家外包的队。原来「不敢动」领着工钱。

罗小满的手机震了三次。前两下他没动，第三下才拿起来。

屏幕上两个字：表哥。手机翻扣在腿上。

沈砚没问，只把项目部四个字抄得很慢。

下午四点，龙潭老码头。陆阿全蹲在船板边补网，八十一岁。

梭子在他手里来回。原来老人不急。

沈砚蹲在旁边，先说事：一条旧船牌的登记，他替老人查。

老人手上没停。「江里捞上来的无主骨头，不能装空棺。」

「棺底压一块江石。压不住，就绝户。」梭子慢了一下。

「迁坟不叫迁坟，叫起骨。把先人请回土里，是孝事。」

沈砚一字一字记，记到「空棺」，笔尖顿住。

空棺是棺里没东西，空穴是穴里没东西。差一个字就反了。

可三户念的是「空葬」。谁把这两个字捏到一处的？

回组六点半。他从书柜最下层抽出民国《临江县志》。

纸页发脆，一翻就有细响。

风俗卷三，江涨条下：「江涨迁坟，起骨易棺，压石镇穴。」

他把两句并排写在纸上。两行隔着三指宽。

写完看了一遍。禁忌拦的是空棺，所以迁坟不算犯忌。

有人把「棺」换成「穴」，一句话就倒过来了。原来只要换一个字。

三月十八下午三点。陈立自己来的，穿夹克，没带人。

他说来做工作，把罗小满叫到履带后面，抽出一个信封。

信封有厚度，里面是新票子。六千，就这个厚度。

罗小满没推也没收，捏着信封走回人群中间。

他走得很慢。慢到所有人看见他手里有东西。

他把信封举过肩，按下录音。屏幕上的秒数开始跳。

「三月十八号，下午三点，龙潭滨江迁坟工地。」

「你给我这个信封，里面六千。让我别往项目部那边查。」

六千。罗小满一个月挣不到这个数。

他把手机递到陈立面前：「你再说一遍。」陈立没接。

他的脸白了一层，像被人抽走一张纸。原来他也没想到会被念出来。

他转身走了，走到坡下也没回头。所以这信封给的是钱。

沈砚把三样东西摊在石板上：县志页、口述记录、派工单。

派工单按户计价，一户一千二。三户三千六，难怪一起拒迁。

三千六买不动一座坟，买得动三户人闭嘴。

他只问一句：「空葬是棺空，还是穴空？」

倪长根往后退了半步，脚后跟碾出一个小坑。退半步就是认了。

坑里是干土，碾不实。「上头让这么说的。」

老唐把回执压在石板上，正好盖住派工单。

红印没干，风一吹纸角抖。所以从这一刻起，这不是协查了。

冯桂英站起来，扶着矮凳。「起骨可以。棺底压一块江石。」

「石头我自己去江滩上捡。」原来她要的不是赔偿。

她没有道谢。原来一个人认了理，是不用道谢的。

042归档，附注写：民国《临江县志》卷三。

第二天他填调阅单，申请调2017年XW专库同源卷。

郑维山在调阅室当面签字，笔尖很稳。稳得挑不出一个字。

「按程序走，一页不少你。」他把单子推回来。

卷宗调出来，蓝布封皮，绳子勒得紧。

第17页的位置，是一道齐口。

前后两页对得上，中间那页没了。难怪对得这么齐。

谁能从专库里取走一页，还让它空得这么齐？

调阅登记卡夹在封底。上一次调阅：2017年6月19日。

四年前。所以这一页的账，四年前就记上了。

调阅人一栏被刀片刮过，起了白茬。原来刮的人手也抖。

没刮干净，剩「沈」字左半边，三点水，一竖。

很久，他没伸手去摸。

原来刮掉一个名字，比写上它更费力。

楼梯间，声控灯亮了一下又灭。原来这层没人。

韩素秋在转角拦住他：「别在审批线上硬碰。」

她说完就走，两步后又停下，回头。灯又亮了。

「第17页的事，你别问郑馆长。」
