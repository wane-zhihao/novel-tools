# 文风设定（以纵横 dushi 组实测区间为约束）

> 数据来源：`F:/小说/platforms/zongheng/harness/genre-baselines.json`，**dushi 组，n=24**（8 本 × 前 3 个免费章 = 24 章实测）。
> 注意：基准文件零反例，只能给「正例分布」，不能当「合格边界」；B 级闸门不设质量型边界。

## 1. 四项硬指标（必须落在 dushi 组实测区间内）

| 指标 | dushi 实测区间 | 本项目落点 |
|---|---|---|
| 句长中位 | **10.0–33.77 字** | 目标 18–26 字；不必套用七猫的 15–27 中位，上限可放到 32 |
| 段/千字 | **24.79–74.78** | 日常 30–45；宽区写作，靠近 70 即视为注水信号 |
| 对话占比 | **0.04–0.42** | 目标 0.25–0.38（协查问话天然高对话，现场动作段压低） |
| 因果密度（因果连词/千字） | **0.05–7.49** | 允许低：交付章 3–6，允许整章接近下限，靠现场动作推进而非因果词 |

## 2. 辅助指标（同组实测，一并抄录）

- 叙述动作密度：**12.83–46.53 / 千字**——现场段的主推手，考据细节要写成动作（翻卷、对页、递纸）而不是讲解。
- 疑问密度：**1.16–12.9 / 千字**——问话与档案设问使用。
- 动作链上限：**2.0–5.0**——单段动作链不超过此数。
- 可见字数：**1665.15–2718.65 / 章**——单章目标 1900 字上下（选题报告：实测中位 1925、p05 1700）；不为「像大章」拉到 3000；日更 3000 = 一天两章。

## 3. 结构文风

- 章名 = 档案编号：「异闻档案·NNN｜俗名」。
- 三拍固定：接案（编号入档）→ 现场（考据细节当证据链）→ 归档（真相 + 处置 + 代价）。
- 章末「卷宗附注」：注明本章民俗的真实出处。
- 交付物语言必须写明「真相 / 处置 / 代价」三件套，不写「又推进了一点」。

## 4. 语体

- 叙述：短句为主，名词化场景，不用感叹号堆情绪。
- 对话：口语化但带身份差——机关语域（韩素秋、郑维山）、派出所语域（高翔、老唐）、老街居民语域（周慕松、罗小满）三者不混。
- 考据质感：卷次、编号、年份必须精确到可核对；不确定的出处不写。

## 5. 闸门

- 每次检查跑：`gate_runner.py --platform .../zongheng --genre dushi`。
- 指标只对照 dushi 组区间；玄幻（n=9）与历史（n=9）区间不当写作约束。
